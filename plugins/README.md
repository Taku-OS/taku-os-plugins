# Plugin layout and manifest / 插件目录及清单

Each submitted version consists of `packages/<name>-<version>.zip` and `index/<name>/<version>.json`, exactly as generated by `taku-plugin pack`. The ZIP contains a single `<name>/` directory with `.codex-plugin/plugin.json` and its declared content. `plugins/` documents the format; it is not an additional source tree to upload.

每个版本由 `taku-plugin pack` 生成的包 `packages/<name>-<version>.zip` 和索引 `index/<name>/<version>.json` 组成。ZIP 仅包含一个 `<name>/` 根目录，其中含 `.codex-plugin/plugin.json` 及声明的内容；`plugins/` 用于格式文档，不需要重复上传源码。

## Manifest / 清单

`name` is lowercase letters, digits and hyphens (1–64 characters, starting with a letter or digit); `version` is `major.minor.patch` with the optional suffix accepted by the creator. `description` is nonempty. `taku.capabilities` and `taku.permissions` are arrays of nonempty strings, empty only when none apply. At least one of `skills` or `mcpServers` must be a relative path within the plugin. `skills` points to a directory containing at least one child directory with `SKILL.md`; `mcpServers` points to a JSON file with an `mcpServers` object. Optional native fields such as `author` and `interface` are preserved. The [JSON Schema](manifest.schema.json) checks the manifest shape; CI also checks paths and package/index consistency.

名称为小写字母、数字和连字符；版本遵循创建器支持的 `major.minor.patch` 格式；描述不能为空。必须声明 `taku.capabilities` 和 `taku.permissions` 数组；`skills` 或 `mcpServers` 至少一个，路径须位于插件内部。`skills` 目录至少有一个含 `SKILL.md` 的子目录；`mcpServers` 指向包含同名对象的 JSON 文件。可保留 `author`、`interface` 等原生字段。JSON Schema 检查结构，CI 另检查路径及包与索引的一致性。

```json
{"name":"status-tip","version":"1.0.0","description":"A reminder","skills":"./skills/","taku":{"capabilities":["show a reminder"],"permissions":[]}}
```
